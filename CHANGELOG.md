# Changelog

## 0.1.0

Initial version.

- Watch saved file changes recursively in any directory, with or without Git.
- Combine multiple directories, including nested repos and linked worktrees.
- Show full-width diff cards, line numbers, change counts, and startup progress.
- Follow locally recorded commits, pushes, pulls, and fetches when Git is available.
- Install and update directly from the GitHub repository in a user-owned bin directory.
- Download and validate both programs before replacing installed copies.

See the README for current monitoring limits and platform support.
