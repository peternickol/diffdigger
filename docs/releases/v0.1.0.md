Diffdigger streams saved file diffs into your terminal so you can watch agents,
editors, and scripts work across your projects.

- Watch any directory recursively; Git is optional.
- Follow multiple folders and nested repositories in one feed.
- See full-width diff cards and progress while the startup baseline loads.
- See locally recorded Git commits, pushes, pulls, and fetches alongside diffs.
- Install locally and update with `diffdigger --update`.

Requires Python 3.10 or newer. The installer targets Linux and macOS; Windows users
can run it inside WSL. GitHub Actions checks both Linux and macOS before the draft
release is created.

The feed compares each saved file with its previously observed contents. It checks
periodically, so rapid saves may be combined. Binary/non-UTF-8 files and files over
1 MiB receive summaries. Git operations are visible only when they leave detectable
local records. File contents are not redacted from the terminal output.

See the README for installation, usage, and current limitations.
